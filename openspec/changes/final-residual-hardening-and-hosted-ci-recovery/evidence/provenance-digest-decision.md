# Provenance digest decision

**Decision: `NOT JUSTIFIED`.** The authoritative gates had reproducible fail-open behavior; those defects have been repaired directly and have negative tests. No remaining demonstrated artifact passes the repaired strict gates and is rejected by an additional source digest. A tree digest would not independently prove which compiler inputs produced the selected executable bytes.

## Exact claim

`boundToHead=true` means the selected binaries report the current Git commit identity and the set is consistent. `boundToTree=false` / `NOT_EMBEDDED` means no binary embeds a source-tree identity. `sourceClean=true` is a Git working-tree observation at gate time, including tracked and non-ignored untracked paths. `stateDigest` is a hash of the canonical Git identity and changed-path lists; it is not a content digest and not a build attestation. Selected binary hashes and package-manifest comparisons identify executable and packaged bytes, not compiler provenance.

Therefore the residual toolchain/generated-input question is documented rather than represented as solved by a source digest. It requires an independently verified build-input attestation or reproducible-build comparison, which is outside this change's proven behavior.
