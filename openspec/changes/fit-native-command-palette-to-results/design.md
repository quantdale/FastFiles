## Decision
Keep existing maximum width/height and placement expressed as UiMetrics. Use actual native list row height and result count (one inert row for no matches) to allocate complete visible rows up to the viewport cap. Compute query anchor from the maximum envelope, independent of the filtered height, so typing never moves the edit. Constrain controls inside the client at narrow/small sizes. Reposition after filtering, including no-match recovery. Preserve live availability updates in place, caret/selection/scroll, native keyboard/WS_VSCROLL/owner-draw/UIA controls and show/hide z-order flags. No animation or color change.
